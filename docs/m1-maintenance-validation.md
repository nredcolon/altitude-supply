# 山海供供货维护迭代验证

日期：2026年10月14日。软件版本：0.2.0-alpha.2。本轮交付为 M1 供货维护迭代，未发布到线上，不代表完整货盘试用版已验收。

## 已实现

- 山海供首页、商户入口和运营入口；商户使用入驻链接自动带入邀请码，登录返回后继续申请。
- 商品图片上传与私有读取，支持 JPG、PNG、WebP，最大5 MB；运营可补充已审核商品的图片。
- 已审核供货快捷改价、改量和改交期；续期必须确认原条件；运营快捷代录记录核实依据。
- 首页按实际货盘显示审核与维护待办，供货列表可按有效、待审核、即将到期、过期及暂停筛选。
- 商户经营资料修改与重新审核；商户导航收敛为首页、我的供货和我的。
