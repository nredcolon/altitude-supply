# 山海供账号交接迭代验证

日期：2026年10月14日。软件版本：0.2.0-alpha.3。范围为 M1 商户档案认领与运营成员管理；本轮没有部署线上，也不代表 M1 已通过真实商户试用。

## 本轮交付

1. 运营在未绑定账号的商户卡片生成专属认领链接，商户进入 `/accept`，登录并填写本人姓名、联系方式。
2. 提交认领申请不授予访问权限。运营在「账号与成员」通过原登记联系人核实，填写依据后绑定原商户档案。
3. 认领保留原商户编号、准入状态、标准商品关联、供货报价和版本。未准入商户认领后仍需准入审核；已准入商户可维护原有报价。
4. 负责人可以邀请、核实、停用和恢复运营成员。普通运营可以维护货盘、审核商户和核实商户认领，不能授予运营权限或管理其他运营成员。
5. 未完成邀请七天有效，可撤销；同一商户重新生成邀请会撤销旧邀请及待核实申请。已绑定商户不允许再次认领。
6. 专属邀请只保存 SHA-256 摘要，明文仅生成时返回。登录身份由服务端取得，客户端不能指定被绑定账号。通用入驻码与专属邀请不能混用。
7. 邀请、申请、核实、撤销、停用及恢复均留下操作记录。并发变化通过空间版本号保护。旧空间缺少新增字段时按空数组读取，无须重建数据或执行新迁移。

本地接口测试只新增明确标注的示例商户、商品、供货及邀请。测试报价结束后暂停，测试邀请结束后撤销；未修改原商户资料、向他人发送邀请或产生采购承诺。

## 试用操作路径

- 负责人 / 运营：商户入驻 → 未绑定商户 → 生成专属认领链接 → 将链接交给已核实的商户联系人。
- 商户：专属链接 → 登录 → 核对档案名称 → 填写本人姓名、联系方式 → 提交申请。
- 运营：账号与成员 → 待核实申请 → 通过原登记联系人确认 → 填写依据 → 核实并绑定。
- 商户：刷新核实结果 → 进入工作台 → 维护自己的原供货记录。
- 负责人：账号与成员 → 生成运营邀请 → 受邀人申请 → 核实并绑定；离岗时填写原因并停用权限。
