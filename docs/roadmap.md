# 山海供开发路线图

更新日期：2026年10月15日。功能范围和规则以[产品功能与版本规划](product-plan.md)为准。本页记录开发进度；产品版本与软件包版本分别管理。

供货平台对商户免费。商户提前维护标准商品及有效供货条件，系统根据采购需求匹配供应商；付费社群身份不参与匹配，不建设逐单询价和商户回复流程。

供给侧顺序：商户入驻 → 标准 SKU 库 → 商户供货维护 → 自动匹配组货 → 对外报价。海外选品端在货盘基础具备后接入：公开选品 → 提交采购清单 → 运营承接 → 自动组货与报价。

产品版本顺序为 V0.1 货盘 → V0.2 海外选品 → V0.3 自动组货 → V1.0 选品到报价闭环。保留原 M1、M2、M3 开发任务编号，新增 B1 海外选品里程碑。

## B1 海外选品与询价

对应 V0.2 海外选品试用版。依赖：M1 有经核实且可公开展示的商品与供货来源。状态：待开发。

- [ ] B1-01 独立对外商品资料、英文内容、图片审核、发布状态、标准 SKU 关联。
- [ ] 同一 SKU 对外一个商品条目，多供应商供货在内部匹配；失效货源联动展示状态。
- [ ] 商品和专题货盘公开链接、分享预览、搜索可读的页面信息。
- [ ] B1-02 手机与电脑端分类、关键词搜索、详情、规格与数量选择、选品清单。
- [ ] B1-03 免注册询价、联系资料、目的地和采购时间、找货附件、提交回执和重复提交保护。
- [ ] 线上询价和运营代录共用需求对象、来源标记、运营队列、负责人和跟进记录。
- [ ] 商户查看关联商品的海外展示状态和分享链接。
- [ ] B1-04 公共数据隔离、表单与附件防滥用、真实海外网络与多设备试用。

验收案例：海外采购商无需注册，从专题货盘选择3个不同 SKU、填写规格数量及联系方式，提交后后台完整接收需求及来源。公开页面没有内部底价，所有供货失效时如实提示待核实。首期由运营人工跟进，尚未实现的自动组货不对外宣称已可用。

## M2 自动匹配组货

对应 V0.3 自动组货版。依赖：M1 的同款关系及价格口径能够可靠核实，B1 需求对象可复用。

- [ ] M2-01 复用线上及代录采购需求，补齐 SKU 映射、数量单位和国内交货约束核实。
- [ ] 海外期望到货时间和国内交货截止时间分别保存，由运营核实转换。
- [ ] 按规格、交期、交货地点、有效性过滤候选供货。
- [ ] M2-02 考虑起订量和包装倍数的多供应商数量组合。
- [ ] 同 SKU 重复需求不重复使用同一货源；不同交货条件下共享可用量。
- [ ] 在每个 SKU 的可行组合中比较成本；同成本减少供应商数量，不承诺跨 SKU 全单最优。
- [ ] 输出缺口、排除原因、成本与供货条件快照。
- [ ] M2-03 运营调整方案，重新校验、保留版本并记录原因。
- [ ] 非贪心数量组合样例与手工结果核对，验证支持范围和性能。

验收案例：客户要500件，甲400件、乙200件、丙有货但超交期；系统分配符合规则的500件。无可行组合时明确说明缺口。最低价贪心无法满足但存在其他合法组合时，能找到可行结果。

M2 只试算、不扣量。数量预占的开发移至 M3，与客户报价确认一并验收；数据接口预留有效预占及执行占用后的可用量读取。

## M3 对外报价与执行交接

对应 V1.0 选品到报价闭环版。依赖：B1 采购入口可用，M2 方案和供货条件快照可追溯。

- [ ] M3-01 将内部方案转为客户版报价，销售单价独立维护。
- [ ] 报价币种、费用边界、交货及付款说明、有效期和不可变版本。
- [ ] 外文商品名、双语字段、客户版预览与 PDF 导出，不泄露内部信息。
- [ ] M3-02 客户反馈与确认对应具体版本；确认后复核最新供货条件。
- [ ] 原子预占、重复确认保护、并发数量校验、到期处理和释放记录。
- [ ] M3-03 分供应商导出执行清单、转执行占用、交接及完成记录。
- [ ] 取消或失效数量经核实再回补自由可供量，交接不自动释放数量。
- [ ] R-01 海外选品到报价和交接的真实业务演练、权限和报价隔离、并发、备份恢复及部署验证。

验收案例：500件方案形成不含供应商底价的客户报价；客户确认指定版本后，最新条件复核成功才一次性预占500件。重复提交不多扣数量，并发方案不会超配；失效与交接后的数量能追溯。

## 后续版本与参考工期

- V1.1：批量导入和维护、需求导入、重复采购、提醒、阶梯价与辅助找品。
- V1.2：商户执行任务、备货交货、差异处理及实际履约记录。
- V2.0：依据真实交易逐项增加仓储物流、专业服务、收付款、结算和售后。
- 海外采购端扩展：买家账户、历史采购、在线报价确认、重复补货和支付，按真实使用需求另排。

按一名全职全栈开发和一名持续参与的业务运营，复用现有 M1：基础体验补齐5至7天、海外选品询价6至9天、自动组货8至12天、报价交接7至10天、集中试用4至6天，共约30至44个开发工作日。外文内容由运营提供，工期依赖真实资料和登录、存储、部署服务，不承诺固定发布日期。
